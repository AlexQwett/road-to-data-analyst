# Database Conventions

## Naming
- All tables are named in the singular.
- Names are written in snake_case.
- The primary key has the format table_name id.

## Data Types
- For all ID use BIGINT GENERATED BY DEFAULT AS IDENTITY.
- created_at is of type TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP.
- updated_at is of type TIMESTAMP and can be NULL.
- Logical values ​​are stored in BOOLEAN
- For money use NUMERIC(10,2).
