| Поле | Тип даних | Чому саме він? |
|-------|-----------|----------------|
| product_id | BIGINT GENERATED BY DEFAULT AS IDENTITY | Первинний ключ, великий запас значень |
| category_id | BIGINT | Зовнішній ключ на category |
| brand_id | BIGINT | Зовнішній ключ на brand |
| name | TEXT | Назва товару без обмеження довжини |
| sell_price | NUMERIC(10,2) | Точне зберігання ціни |
| weight_g | INTEGER | Вага в грамах |
| created_at | TIMESTAMP | Дата і час створення |
| updated_at | TIMESTAMP | Дата і час останнього оновлення |
| is_active | BOOLEAN | Активний чи ні |
