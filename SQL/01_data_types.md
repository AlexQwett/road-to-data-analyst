# SQL Data Types (PostgreSQL)

## Numeric Types

| Тип | Використання | Приклад |
|------|--------------|----------|
| INTEGER | Цілі числа | quantity |
| BIGINT | ID | product_id |
| NUMERIC(10,2) | Ціни | sell_price |

## Text Types

| Тип | Використання | Приклад |
|------|--------------|----------|
| TEXT | Назви, опис | name |
| VARCHAR(n) | Обмежена довжина | phone |
| CHAR(n) | Фіксована довжина | Майже не використовуємо |

## Date & Time

| Тип | Використання |
|------|--------------|
| DATE | День народження |
| TIMESTAMP | created_at, updated_at |

## Boolean

| Тип | Використання |
|------|--------------|
| BOOLEAN | is_active |

## Висновки

- Для грошей використовуємо `NUMERIC(10,2)`.
- Для ID використовуємо `BIGINT GENERATED BY DEFAULT AS IDENTITY`.
- Для назв переважно використовуємо `TEXT`.
- Для часових міток — `TIMESTAMP`.
